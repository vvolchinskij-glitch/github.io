Політика конфіденційності

Застосунок «Marzipan 1C» · редакція від 29.09.2026

1. Про застосунок

«Marzipan 1C» — внутрішній інструмент пекарні Marzipan. Облікова система компанії (BAS / 1С) використовує його, щоб читати внутрішні Google-таблиці компанії з плануванням виробництва і постачання та створювати на їх основі замовлення в обліку.

2. Які дані Google ми отримуємо

Застосунок запитує лише дозвіл spreadsheets.readonly — перегляд Google-таблиць. Фактично читаються тільки таблиці компанії, до яких службовому обліковому запису надано доступ: назви виробів, дати, коди точок продажу і кількості. Застосунок не може змінювати, створювати чи видаляти таблиці та не має доступу до пошти, контактів, файлів Google Диска чи інших даних облікового запису.

3. Як дані використовуються

Прочитані значення використовуються виключно для створення документів замовлень у внутрішній обліковій системі компанії. Дані не продаються, не передаються третім особам, не використовуються для реклами і не використовуються для навчання моделей штучного інтелекту.

4. Зберігання і захист

Токени доступу Google зберігаються в захищеному сховищі облікової системи на сервері компанії, доступ до якого мають лише адміністратори. Обмін з Google відбувається тільки через HTTPS. Дані з таблиць зберігаються лише у вигляді облікових документів компанії.

5. Відкликання доступу

Доступ можна відкликати будь-коли на сторінці myaccount.google.com/permissions або кнопкою «Видалити авторизацію» в обробці обліку.

6. Відповідність політиці Google

Використання та передача інформації, отриманої через API Google, відповідає Google API Services User Data Policy, включно з вимогами Limited Use.

Privacy Policy

“Marzipan 1C” application · effective 29 Sep 2026

1. About the application

“Marzipan 1C” is an internal tool of the Marzipan bakery. The company's accounting system (BAS / 1C) uses it to read the company's internal Google Sheets with production and delivery plans and to create orders from them.

2. Google data we access

The application requests only the spreadsheets.readonly scope. In practice it reads only the company spreadsheets shared with the service account: product names, dates, outlet codes and quantities. It cannot modify, create or delete spreadsheets and has no access to Gmail, contacts, Google Drive files or any other account data.

3. How data is used

The values read are used solely to create order documents in the company's internal accounting system. Data is not sold, not shared with third parties, not used for advertising and not used to train AI models.

4. Storage and security

Google access tokens are kept in the protected storage of the accounting system on the company server, accessible to administrators only. All communication with Google uses HTTPS. Spreadsheet data is retained only as the company's accounting documents.

5. Revoking access

Access can be revoked at any time at myaccount.google.com/permissions or with the “Remove authorization” button in the accounting tool.

6. Google policy compliance

Use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.
